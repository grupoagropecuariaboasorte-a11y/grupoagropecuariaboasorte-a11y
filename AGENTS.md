# Instruções e Regras do Projeto

- **Repositório GitHub**: `https://github.com/grupoagropecuariaboasorte-a11y/grupoagropecuariaboasorte-a11y.git`
- **Git & GitHub Automático**: Ao final de cada ciclo de alterações ou implementações concluídas no código, realize o `git add .`, crie um `git commit` descritivo e faça o `git push origin main` para manter o repositório do GitHub sempre sincronizado. Caso o remote `origin` não esteja configurado após reciclagem do container, restabeleça o remote origin e faça o push para a branch `main`.
